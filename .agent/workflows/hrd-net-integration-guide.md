# HRD-Net / 승인기관 연동 방법

**“우리 센터가 승인받은 과정 목록”**을 HRD-Net·승인기관 쪽에서 **자동으로 받아오려면** 어떻게 해야 하는지 정리한 문서입니다.

---

## 1. 현재 공개된 것 vs 없는 것

| 구분 | 내용 |
|------|------|
| **공개된 오픈 API** | 공공데이터포털·한국산업인력공단이 제공하는 API는 **기준/자격 정보**(종목, 편성기준, 훈련시간 등) 조회용입니다. **특정 훈련기관의 승인받은 과정 목록**을 조회하는 API는 공개 문서에서 확인되지 않습니다. |
| **HRD-Net 행정지원시스템** | 훈련기관이 **통합설치프로그램**을 설치하고 **공인인증서**로 로그인해 훈련과정·승인 정보를 입력·관리합니다. 이 시스템을 **REST API로 직접 연동**하는 방법은 공개되어 있지 않습니다. |

따라서 **“API 키만 넣으면 우리 센터 승인 과정이 자동으로 내려온다”**는 형태의 공식 연동은, 현재 공개 정보만으로는 불가능합니다.  
아래는 **가능한 연동 경로**와 **해야 할 작업**입니다.

---

## 2. 연동 경로별로 해야 할 일

### 경로 A: 공공데이터 오픈 API로 “기준 정보”만 가져오기

**의미**  
- “우리 센터 승인 목록”이 아니라, **과정평가·일학습병행 자격/편성기준**(종목코드, 편성기준명, 교육훈련기준시간 등)을 API로 조회해, **승인받은과정 입력 시 참고/자동채우기**에 쓰는 방식.

**할 일**

1. **공공데이터포털** [data.go.kr](https://www.data.go.kr) 접속 → 회원가입/로그인.
2. 아래 API **활용신청** (인증키 발급).
   - **한국산업인력공단_HRDNET 연계 정보** (데이터셋 15089015)  
     - URL 예: `https://c.q-net.or.kr/openapi/Hrdninfo/hrdnetOrganStdInfo.do`  
     - 제공: 종목코드, 편성기준명, 교육훈련목표, 교육훈련기준시간 등.
   - **한국산업인력공단_NCS 훈련과정정보** (15086447)  
     - 대분류·능력단위명으로 훈련과정 정보 조회 (이미 우리 쪽 NCS_API_KEY 연동에 사용 중).
3. 발급받은 **인증키(ServiceKey)** 를 우리 서버 환경변수에 설정 (예: `HRD_API_KEY` 또는 기존 `NCS_API_KEY`와 동일 키 사용 가능 여부는 포털에서 확인).
4. 우리 백엔드에 **HRDNET 연계정보 조회 API** 호출 로직 추가  
   - 예: `GET /api/hrd/approved-standards?pageNo=1&numOfRows=50`  
   - 응답을 가공해 **승인받은과정** 등록 화면의 “편성기준/종목/훈련시간” 등 **자동 채우기** 또는 선택 목록으로 사용.

**정리**  
- “승인받은 과정 **목록**”을 우리 센터 단위로 조회하는 API는 아님.  
- “**기준 정보**를 가져와 과정 등록 시 활용”하는 연동입니다.

---

### 경로 B: 한국산업인력공단에 “훈련기관 승인과정 조회” 문의

**의미**  
- **우리 센터가 승인받은 과정만** 조회·연동하려면, 공개 API가 아니라 **훈련기관용 API·데이터 제공**이 있는지 공단에 직접 문의하는 것이 필요합니다.

**할 일**

1. **문의처**  
   - 한국산업인력공단 **1644-8100** (지사별 직업능력개발부 안내 받기).
2. **질문 예시**  
   - “HRD-Net 행정지원시스템에 등록된 **우리 훈련기관의 승인받은 훈련과정 목록**을 외부 시스템(우리 LMS)에서 조회·연동할 수 있는 **API 또는 데이터 제공(엑셀/파일 배포)** 이 있나요?”  
   - “있다면 신청 절차, 인증 방식(API 키, 공인인증서 등), 제공 형식(JSON/XML/파일)을 알려주세요.”
3. **가능하다고 하면**  
   - 제공되는 API 스펙·인증 방식에 맞춰 우리 백엔드에 **승인과정 조회·동기화** 기능 구현 (예: 주기 배치 또는 “동기화” 버튼).
4. **“API는 없고 행정지원시스템에서만 조회 가능”이라고 하면**  
   - 경로 C(수동/엑셀) 또는 행정지원시스템 화면에서 복사·정리 후 우리 쪽 **엑셀 업로드**로 갈음.

**정리**  
- **HRD-Net/승인기관 연동**으로 “우리 정보만 받아오기”를 하려면, 이 문의 단계가 사실상 필수입니다.

---

### 경로 C: 수동 입력 + 엑셀 업로드

**의미**  
- API로 “우리 센터 승인 과정”을 받아오지 않고, **승인서·공문·행정지원시스템 화면**을 보고 우리 플랫폼에 직접 입력하는 방식. 필요 시 **엑셀 일괄 업로드**로 보완.

**할 일**

1. **지금도 가능한 것**  
   - `/admin/courses/approved` 에서 “승인받은 과정 등록”으로 **수동 입력**.
2. **추가하면 좋은 것**  
   - **엑셀/CSV 일괄 업로드**  
     - 예: `POST /api/approved-courses/import` API + 관리 화면에 “엑셀 업로드” 버튼.  
     - 엑셀 양식(과정명, 훈련시간, NCS코드 등)을 배포하고, 업로드 시 미리보기 → 저장.  
   - 행정지원시스템이나 승인기관에서 받은 **엑셀/파일**이 있으면, 그 양식에 맞춰 import 로직 설계.

**정리**  
- HRD-Net/승인기관 **자동 연동**이 어렵거나 늦어질 때 당장 쓸 수 있는 방법입니다.

---

## 3. 권장 순서

1. **경로 B**  
   - 한국산업인력공단(1644-8100)에 **“훈련기관 승인과정 조회 API/데이터 제공 여부”** 문의.
2. **API/데이터 제공이 있다고 하면**  
   - 제공 스펙에 맞춰 **승인과정 조회·동기화** 기능 구현 (경로 B 연동).
3. **공개 API는 기준 정보만 가능하다고 하면**  
   - **경로 A**로 HRDNET 연계정보·NCS 훈련과정정보 API를 활용해 **과정 등록 시 기준 정보 자동 채우기** 구현.  
   - “우리 센터 승인 목록”은 **경로 C**(수동 + 엑셀 업로드)로 유지.
4. **당장 자동 연동이 불가하면**  
   - **경로 C**만 사용(수동 입력 + 필요 시 엑셀 업로드 기능 추가).

## 4. 참고: 공공데이터 HRDNET 연계 정보 API (15089015)

| 항목 | 내용 |
|------|------|
| **서비스 URL** | `https://c.q-net.or.kr/openapi/Hrdninfo/hrdnetOrganStdInfo.do` (실제 URL은 포털 상세페이지 확인) |
| **인증** | 공공데이터포털 인증키(ServiceKey, URL-Encode) |
| **요청변수** | type(json/xml), pageNo, numOfRows, ServiceKey |
| **출력 예** | 종목코드(itemCd), 편성기준명(ogztnStdrNm), 교육훈련목표(etraGoalCn), 교육훈련기준시간합계(etraStdrTimeSm) 등 |
| **용도** | 과정평가·일학습병행 **자격/편성기준** 참고용. “특정 기관 승인 목록”이 아님. |

이 API를 우리 서버에서 호출해 **편성기준·훈련시간** 등을 조회하고, **승인받은과정** 등록 시 선택/자동입력에 쓰는 것은 **경로 A**에 해당합니다.

---

## 5. 요약

| 목표 | 방법 |
|------|------|
| **우리 센터 승인 과정 목록을 자동으로 받아오기** | **한국산업인력공단(1644-8100) 문의**로 훈련기관용 API·데이터 제공 여부 확인 후, 있으면 그에 맞춰 연동 개발. 공개 문서상으로는 해당 API가 없음. |
| **기준 정보(종목, 편성기준, 훈련시간)를 API로 가져와 과정 등록에 활용** | **공공데이터 HRDNET 연계정보 + NCS 훈련과정정보** 활용신청 → 인증키 설정 → 우리 API에서 호출 후 승인받은과정 입력 화면에 반영(자동채우기/선택 목록). |
| **당장 자동 연동이 어렵다** | **수동 입력** + **엑셀 일괄 업로드** 기능으로 보완. |

즉, **HRD-Net/승인기관 연동**을 하려면  
1) **공단 문의로 “훈련기관 승인과정 조회” 가능 여부 확인**하고,  
2) 가능하면 그 방식으로 연동, 불가하면 **공개 API는 기준 정보만 쓰고**, **승인 목록은 수동·엑셀**로 처리하는 구성이 현실적입니다.
