# HRD 교육센터: 사전 승인 정보 → 과정 등록 활용 작업 가이드

와우쓰리디 쿠키 홍대센터처럼 **사전에 교육과정을 승인받아 교육을 진행하는 HRD 교육센터**가, **승인받은 정보를 받아와 과정 등록에 활용**하려면 아래 작업을 순서대로 진행하면 됩니다.

---

## 1. 현재 우리 플랫폼에 이미 있는 것

| 구분 | 내용 |
|------|------|
| **승인받은 과정** | `approved_courses` 테이블 + API + 관리 화면 (`/admin/courses/approved`) |
| **회차별 과정개설** | `course_sessions` 테이블 + API + 관리 화면 (`/admin/courses/sessions`) |
| **과정분류** | `course_categories` + `/admin/courses/categories` |
| **NCS 검색** | `GET /api/ncs/search` (NCS_API_KEY 있으면 공공데이터 API, 없으면 Mock) |

즉, **“승인받은 과정”을 등록·관리하고, 그걸 바탕으로 “회차별 과정개설”을 하는 구조**는 이미 갖춰져 있습니다.  
부족한 부분은 **“승인 정보를 어디서 어떻게 받아올지”**와 **“그 정보로 입력을 얼마나 자동화할지”**입니다.

---

## 2. 승인 정보는 어디서 오는가

사전 승인 정보는 보통 다음 중 하나(또는 조합)입니다.

| 경로 | 설명 | 우리가 할 작업 |
|------|------|----------------|
| **HRD-Net / 행정지원시스템** | 훈련기관이 공인인증서로 로그인해 과정·승인 정보를 조회·관리 | 공공데이터/한국산업인력공단 API로 **연계 정보** 조회 가능 여부 확인 후 연동 |
| **NCS 훈련과정정보(공공데이터)** | NCS 기준의 훈련과정(훈련목표, 훈련시간, 직종 등) | **이미 제안됨**: NCS API로 검색 → 승인받은과정 입력 시 자동 채우기 |
| **승인서·공문·엑셀** | 기관이 받은 승인서/공문/엑셀을 수기로 입력 | **수동 입력** UI는 이미 있음. 필요 시 **엑셀 일괄 업로드** 기능 추가 |

따라서 할 일은  
1) **어떤 경로로 승인 정보를 쓸지** 정하고,  
2) **그 경로에 맞춰 “받아오기”와 “과정 등록에 활용”**을 구현하는 것입니다.

---

## 3. 해야 할 작업 (체크리스트)

### Phase A: 승인 정보 “받아오기” 경로 정하기

- [ ] **A1. 데이터 소스 결정**
  - NCS 기준 훈련과정만 쓸지, HRD-Net(또는 공단 API) 연동을 할지, 수기/엑셀 위주로 할지 정하기.
  - NCS만 쓸 경우: 공공데이터 **NCS 훈련과정정보**(B490007) 활용신청 + `NCS_API_KEY` 설정으로 진행 가능.

- [ ] **A2. HRD-Net/공단 API 조사 (선택)**
  - 공공데이터포털에서 **“한국산업인력공단”**, **“HRDNET”** 검색 후, 훈련기관·과정·승인 관련 오픈 API가 있는지 확인.
  - 예: [HRDNET 연계정보](https://www.data.go.kr/data/15089015/openapi.do) 등. 있으면 활용신청 후 우리 API에서 호출해 `approved_courses`에 매핑.

- [ ] **A3. 수기/엑셀 입력 보강 (선택)**
  - 승인서·엑셀을 그대로 입력할 경우: 현재 “승인받은 과정 등록” 폼으로 수기 입력 가능.
  - **엑셀 일괄 업로드**가 필요하면: `POST /api/approved-courses/import` 같은 API + 화면(파일 선택 → 미리보기 → 저장) 추가.

---

### Phase B: NCS 승인 정보로 “과정 등록에 활용”하기

(이미 `.agent/workflows/ncs-approved-courses-integration.md`에 상세 제안되어 있음. 여기서는 할 일만 요약.)

- [ ] **B1. NCS 대분류 목록 API**
  - `GET /api/ncs/approved/large-classes` 구현.
  - NCS 대분류(01~24 등) 고정 목록 또는 공공 API 결과를 JSON으로 반환.

- [ ] **B2. NCS 훈련과정 검색 API**
  - `GET /api/ncs/approved/training?ncsLclasCd=15&cdName=3D&pageNo=1&numOfRows=20` 구현.
  - 공공데이터 B490007 호출 후, 우리 포맷(코드, 명칭, 훈련시간 등)으로 변환해 반환.

- [ ] **B3. DB 확장**
  - `approved_courses`에 `ncs_code`, `ncs_job_name` 컬럼 추가(마이그레이션).
  - 승인받은과정 API에서 두 필드 읽기/쓰기 반영.

- [ ] **B4. 승인받은 과정 등록 화면에 “NCS 연동” 블록 추가**
  - `/admin/courses/approved/register`(및 수정 페이지)에 **“과정개요 및 직종선택”** 블록 추가.
  - 대분류 선택 → 훈련과정 검색(B2 API) → 결과에서 한 건 선택 시 **과정명·NCS 코드·직종명·훈련시간** 등 자동 입력.
  - 기존 NCS교과 URL, 교수계획서 URL 등은 그대로 두고, NCS 연동은 **보조 입력**으로만 사용해도 됨.

---

### Phase C: “승인받은 과정” → “실제 개설 회차” → “과정 등록” 흐름 정리

- [ ] **C1. 플로우 확인**
  - 현재: **승인받은 과정** 등록 → **회차별 과정개설** 등록(1기, 2기, 훈련기간, URL 등).
  - 필요 시: **회차별 과정개설**이 기존 LMS의 `courses` 테이블과 연결되는지 확인. 연결이면 “회차 개설 = 과정 개설”로 동기화 로직 또는 안내 정리.

- [ ] **C2. 회차 개설 시 승인 정보 자동 반영**
  - 회차 등록 폼에서 “승인받은 과정” 선택 시, 해당 승인 과정의 **NCS 코드·직종명·훈련시간·URL** 등을 읽어와 폼에 기본값으로 채우기(이미 `approved_course_id`로 조회 가능하면 API/화면에서 활용).

---

### Phase D: 운영·정책

- [ ] **D1. NCS_API_KEY 및 공공데이터 활용신청**
  - Cloudflare Pages 환경변수에 `NCS_API_KEY` 설정.
  - 공공데이터포털에서 **NCS 훈련과정정보**(15086447) 활용신청 완료.

- [ ] **D2. 승인 정보 갱신 주기**
  - NCS/공단 API는 “기준 정보”이므로, 승인 내용이 바뀔 때만 재검색해 입력하면 됨.
  - HRD-Net 등에서 주기적으로 가져오는 경우: 스케줄(또는 수동 “동기화” 버튼)으로 API 호출 → `approved_courses` 갱신 로직 추가 검토.

---

## 4. 작업 순서 제안

1. **A1** → 데이터 소스 결정(NCS 우선인지, HRD-Net 연동 필요 여부).
2. **D1** → NCS_API_KEY 설정 + NCS 훈련과정정보 활용신청.
3. **B1, B2** → NCS 승인과정용 API 구현.
4. **B3, B4** → DB 확장 + 승인받은 과정 등록 화면에 NCS 연동 블록 추가.
5. **C1, C2** → 회차 개설 시 승인 정보 자동 반영(필요 시).
6. **A2, A3** → HRD-Net API·엑셀 업로드 등은 필요에 따라 추가.

이 순서로 진행하면 **“사전 승인 정보를 받아와서 과정 등록에 활용”**하는 흐름을 단계적으로 갖출 수 있습니다.
