# 교육사진 갤러리 ↔ 관리자 연동 제안

## 현재 구조 (요약)

| 구분 | 경로 | 데이터 소스 | 비고 |
|------|------|-------------|------|
| **관리자** | `/admin/education-gallery` | `posts` 테이블, `category=education_photo` | 교육사진만 등록·수정·삭제 |
| **일반 페이지** | `/education-photos` | 동일 API: `education_photo` + `portfolio` 두 번 호출 | 필터로 "전체 / 교육 사진 / 포트폴리오" 선택 |

- **교육 사진** = 관리자 페이지에서 등록한 항목과 **동일한 데이터**입니다. (`/api/posts?category=education_photo`)
- **포트폴리오** = 같은 `posts` 테이블이지만 `category=portfolio`로, 별도 관리(공개 페이지 모달 또는 다른 관리 화면)로 등록된 항목입니다.

즉, **이미 연동되어 있습니다.** 다만 사용자가 “구분이 안 된다”고 느끼는 이유는 아래와 같이 추정할 수 있습니다.

---

## 구분이 안 되어 보일 수 있는 이유

1. **기본이 "전체"**  
   페이지 로드 시 "전체"가 선택되어 교육 사진과 포트폴리오가 섞여 보임.
2. **시각적 구분이 약함**  
   카드에 작은 뱃지(교육 사진/포트폴리오)만 있어, 한눈에 “관리자 갤러리 = 교육 사진”이 연결된다는 인식이 약함.
3. **관리자와의 연결이 문구로 드러나지 않음**  
   “이 목록은 관리자 > 교육사진 갤러리에서 등록한 내용”이라는 안내가 없음.

---

## 제안 (선택 가능)

### 방안 1: 기본 탭을 "교육 사진"으로 (권장)

- **내용**: `/education-photos` 첫 로드 시 필터를 **"교육 사진"**으로 두고, 교육사진만 먼저 보이게 함.
- **효과**: 접속하자마자 “관리자에서 등록한 교육사진”이 메인으로 보여, **관리자 갤러리와의 연동이 직관적**임.
- **구현**: `currentFilter` 초기값을 `'all'` → `'education_photo'`로 변경.

### 방안 2: URL로 필터 고정 (관리자에서 링크 시 유용)

- **내용**:  
  - `/education-photos` → 기존처럼 전체 또는 기본 필터.  
  - `/education-photos?filter=education_photo` → **교육 사진만** 표시.  
  - `/education-photos?filter=portfolio` → **포트폴리오만** 표시.
- **효과**: 관리자 페이지(`/admin/education-gallery`)에  
  **“미리보기: 교육사진 갤러리”** 버튼을 두고  
  `https://3dcookiehd.pages.dev/education-photos?filter=education_photo` 로 연결하면, **관리자 화면과 공개 갤러리가 명확히 1:1로 연결**된 것처럼 보임.
- **구현**: 페이지 로드 시 `location.search`에서 `filter` 값을 읽어 `currentFilter` 설정 후 `setFilter(currentFilter)` 호출.

### 방안 3: 필터 근처에 안내 문구 추가

- **내용**:  
  - "교육 사진" 필터 옆 또는 위에  
    **“관리자 > 교육사진 갤러리에서 등록한 사진입니다.”** 같은 짧은 문구 표시.  
  - "포트폴리오" 필터 옆에는  
    **“수강생·강사 포트폴리오입니다.”** 등으로 구분.
- **효과**: 교육 사진 = 관리자 갤러리와 연동된다는 점이 **글자로 명시**됨.

### 방안 4: 시각적 구분 강화

- **내용**:  
  - **교육 사진** 카드: 파란 계열 테두리 또는 왼쪽 컬러 바.  
  - **포트폴리오** 카드: 회색/다크 계열 테두리 또는 다른 컬러 바.  
  - 뱃지 크기·위치를 조정해 “교육 사진 / 포트폴리오”가 더 잘 보이게 함.
- **효과**: 스캔만 해도 두 유형이 구분됨.

### 방안 5: 관리자 페이지에 “미리보기” 링크 추가

- **내용**: `/admin/education-gallery` 상단 또는 하단에  
  **“공개 갤러리에서 보기”** / **“교육사진 갤러리 미리보기”** 버튼을 두고  
  `https://3dcookiehd.pages.dev/education-photos?filter=education_photo` (또는 실제 도메인)로 새 탭 열기.
- **효과**: 관리자가 “여기서 등록한 게 저 페이지에 나오는구나”를 한 번에 확인 가능.

---

## 권장 조합

- **즉시 적용 추천**: **방안 1 + 방안 2**  
  - 기본을 "교육 사진"으로 두고,  
  - URL `?filter=education_photo` 지원으로 관리자나 공유 링크에서 “교육사진만” 고정 노출.
- **추가 권장**: **방안 3** 또는 **방안 5** 중 하나 이상  
  - 방안 3: 일반 사용자에게 “교육 사진 = 관리자 갤러리” 인지 도움.  
  - 방안 5: 관리자에게 “등록한 내용이 어디에 나오는지” 바로 확인 가능.

원하시면 방안 1·2·3(또는 5)에 맞춰 실제 수정할 파일과 코드 변경 포인트도 정리해 드리겠습니다.
