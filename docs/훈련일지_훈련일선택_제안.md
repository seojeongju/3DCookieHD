# 훈련일지: 훈련일만 선택 + 마감 과정 제한 제안

## 1. 현재 동작과 문제

- **훈련일 선택**: `<input type="date">` 로 임의 날짜 선택 가능 → 훈련일이 아닌 날짜 선택 시 저장 시점에만 막고, 잘못된 날짜 선택 자체는 막지 못함.
- **마감 과정**: 훈련일지는 추후 보완 작성이 필요하므로, 마감된 과정에서도 작성 가능하도록 제한하지 않음.

## 2. 제안 요약

| 구분 | 제안 | 효과 |
|------|------|------|
| **훈련일 선택** | “지정된 훈련일”만 리스트로 노출해 그 중에서만 선택 | 훈련일이 아닌 날에 일지가 작성되는 일 방지 |
| **마감 과정** | 제한 없음 — 훈련일지는 마감 후에도 추후 작성 가능 | (정책 반영) |

---

## 3. 훈련일만 선택 가능하게

### 3.1 데이터 근거

- **시간표가 있는 회차**: `session_timetable` 의 `training_date` 중 `is_excluded` 가 아닌 날짜만 “훈련일”.
- **시간표가 없는 회차**: `training_start_date` ~ `training_end_date` 구간을 “훈련일”로 간주 (또는 `days_of_week` 이 있으면 해당 요일만).

### 3.2 API 제안

- **GET** `/api/hrd/training-logs/training-dates?courseId={회차ID}`
  - 응답 예:  
    `{ success: true, data: { dates: ["2026-01-06", "2026-01-08", ...], training_start_date, training_end_date, status } }`
  - `dates`: 해당 회차의 “지정된 훈련일”만 정렬된 배열.
  - `status`: 회차 상태 (마감/종료 판단용).

### 3.3 화면 제안

- 훈련일 입력을 **날짜 자유 입력**이 아니라 **“지정된 훈련일” 목록에서만 선택**하도록 변경.
  - 방식 A: `<input type="date">` 대신 **`<select>`** 로 훈련일 목록 표시 (권장).
  - 방식 B: 기존 date input 유지하되 `min`/`max` 설정 + **선택 시 서버의 훈련일 목록과 비교해 훈련일이 아니면 선택 취소/경고**.
- 모달 열 때 위 API로 훈련일 목록 로드 후, 선택 가능한 값만 넣어주면 “훈련일이 아닌 날” 선택 자체가 사라짐.

---

## 4. 마감된 과정과 훈련일지 작성

- **정책**: 훈련일지는 **마감된 과정에서도 추후 작성 가능**하므로, 마감 여부로 신규 작성을 막지 않음.
- API `training-dates` 의 `is_closed` 는 참고용으로만 반환하며, 버튼 비활성화·저장 거절에는 사용하지 않음.

---

## 5. 구현 순서 제안

1. **API**: `GET /api/hrd/training-logs/training-dates` 구현 (훈련일 목록 + `status` 등).
2. **프론트**: 훈련일지 작성 모달에서 훈련일을 `<select>`(훈련일 목록)로만 선택하도록 변경.

이 순서로 적용하면 “훈련일이 아닌 날 일지 작성”을 방지할 수 있습니다. 마감 과정은 훈련일지 추후 작성이 가능하므로 제한하지 않습니다.
